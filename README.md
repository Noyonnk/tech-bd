# Tech BD

A mobile-first digital products storefront starter built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this repository into Vercel and deploy with the default Next.js settings.

## Important

This starter is a demo storefront. Product prices are examples. Login, order storage, real delivery and payment processing are not implemented. Configure a backend and approved payment provider before accepting real orders. Only list subscriptions/licenses you are authorized to resell.
